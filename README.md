# Naufal Nazeer — Portfolio

Personal portfolio site, built with React, Vite and Tailwind CSS.

## Scripts

```bash
npm install      # install dependencies
npm run dev      # start the dev server
npm run build    # production build into dist/
npm run preview  # preview the production build locally
```

## Before deploying

- Add your resume PDF at `public/resume.pdf` — the "Resume" buttons link to it.
- Update `linkedin` in `src/data.js` with your real LinkedIn URL.
- All other content (bio, experience, projects, tech stack) lives in `src/data.js`.
